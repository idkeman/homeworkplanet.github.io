# Third-party source and licensing notes

Homework Planet's Mega Library adds discovery links and a combined index. It does **not** copy or relicense the upstream repositories' game binaries.

## Sources indexed

- **Homework Planet** — existing local HTML game-wrapper pages in this repository.
- **Seraph** — https://github.com/a456pur/seraph — upstream declares GPL-3.0. Its README describes a 350+ game portal and expressly permits extracting games/apps from Seraph; individual third-party game rights may still apply. The live portal is linked; no Seraph code or game binaries are copied by this change.
- **MonkeyGG2** — https://github.com/MonkeyGG2/monkeygg2.github.io — upstream declares WTFPL. Its README says the project is no longer maintained. Entries are indexed as external links; individual games/assets may have separate rights.
- **HTML5 Game Archive** — https://github.com/HTML5GameArchive/gfiles — its README describes an archive of game folders. No blanket license was identified in the repository metadata checked, so entries link to source folders rather than copying files.
- **NettleWeb** — https://github.com/nettleweb/nettleweb — upstream declares MIT for its own code, but its README explicitly asks contributors not to include GPL-3.0/AGPL-3.0 code or libraries. It is linked as an independent portal only.
- **JetYehs** — https://github.com/JetYehs/jetyehs.github.io — reviewed as a reference project; no files copied.
- **Lunaar V7** — the previously supplied repository could not be independently verified during this integration and is not included as a code import.

## Important

The catalog mixes local pages, external game-host URLs, and upstream source-folder links. External games depend on their original hosts and third-party services. Check copyright, trademark, individual game licenses, and takedown status before mirroring any individual title or asset.
